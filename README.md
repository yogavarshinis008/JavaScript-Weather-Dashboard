# SkyCast — Asynchronous JavaScript & RESTful APIs

Responsive weather dashboard built using HTML5, CSS3, and vanilla JavaScript.

## Features
- Search weather by city name
- Uses the Open-Meteo geocoding and forecast REST APIs (no API key required)
- Uses `async`/`await` and Fetch API
- Handles network errors, HTTP errors, and unknown city names
- Reads nested JSON data and dynamically renders current conditions and a five-day forecast
- Responsive layout for mobile and desktop
- Accessible form labels and live status messages

## Run
Keep `index.html`, `style.css`, and `script.js` in the same folder. Open `index.html` in a browser with an internet connection. If your browser restricts API requests from local files, run the folder using VS Code Live Server.

## Data source
Open-Meteo public APIs: https://open-meteo.com/
